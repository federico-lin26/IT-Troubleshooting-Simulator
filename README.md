# 🖥️ **IT Troubleshooting Simulator**

IT Troubleshooting Simulator is a browser-based training tool built using HTML, CSS, and JavaScript.

It simulates common IT support situations by guiding users through troubleshooting workflows and helping them diagnose technical issues.

The application uses decision-tree logic to replicate the process followed by IT support technicians when resolving incidents and generating support documentation.

---

🌐 **Live Demo**

[IT Troubleshooting Simulator](https://federico-lin26.github.io/IT-Troubleshooting-Simulator/)

---

🚀 **Features**

* Interactive troubleshooting scenarios

* Multiple IT support categories

* Decision-tree based diagnostics

* Incident report generation

* Troubleshooting history log

* User-friendly interface

* Restart and navigation controls

---

📋 **How It Works**

1. Select an IT support category.

2. Choose a troubleshooting problem.

3. Answer diagnostic questions.

4. Receive a suggested diagnosis or solution.

5. Generate an incident report.

6. Review the troubleshooting history.
